# albauth feature map

In sweep order. Each file: what it is, how to reach it, how to drive it, the proof.

- [browser-login](browser-login.md) — Logging in with the browser
- [log-redaction](log-redaction.md) — Session values never reach the logs
- [domain-setup](domain-setup.md) — Adding a domain from the command line
- [domain-discovery](domain-discovery.md) — Spotting a domain that needs albauth
